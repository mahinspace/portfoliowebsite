# Shadat Rony – Full‑Stack Marketer & Squidx Co‑Founder Portfolio Website Clone

A high-performance, token-driven, and fully mobile-responsive clone of [Shadat Rony's Official Website](https://shadat.co/).

## 🚀 Features
- **Design System & Tokens**: Styled with `Azeret Mono`, precise color palette (`#050504`, `#faf9f9`, `#f2500d`), and semantic spacing tokens.
- **Mobile Responsive**: Full viewport optimization and zero horizontal overflow across Desktop, Tablet, and Mobile.
- **Clean Architecture**: Stripped of third-party bloatware, tracking scripts, and analytics.
- **Local Server**: Includes a lightweight Node.js server (`server.js`) with proxy fallback for seamless local previews.

## 🛠️ Getting Started

To run locally:
```bash
node server.js
```
Then visit `http://localhost:3000/` in your browser.
